# CAMX 2026 업체 탐색

CAMX 2026 공식 참가업체 명단과 사용자 제공 2025년 참관 보고서를 비교하는 정적 웹페이지입니다. [웹페이지](https://jucho97.github.io/CAMX/)는 GitHub Pages에서 서비스합니다.

## 데이터 범위

- `data/exhibitors-2026-raw.json`: 2026년 9월 19일 [CAMX 공식 참가업체 디렉터리](https://camx2026.mapyourshow.com/8_0/explore/exhibitor-gallery.cfm)에 표시된 505개 항목의 이름과 공식 상세 페이지 ID. 행사 주최 측 부스와 프로그램 항목도 원본 그대로 포함합니다.
- `data/featured.json`: 17개 업체의 테마, 제품, 비교, 개발 방향, 방문 확인 항목과 출처. 이 중 13개는 제공된 2025년 보고서 4–5쪽에 실제로 이름이 나온 업체입니다. 보고서 표지에는 19개 업체라고 쓰여 있으나 제공된 파일에는 나머지 6개 업체의 이름이 없습니다.
- 13개 중 9개는 2026년 공식 명단에서 재확인됐습니다. ThermHex, Helicoid Industries, Rockfiber, NextGen Preforms는 해당 날짜 명단에서 찾지 못했습니다. 명단 미확인은 불참 확정을 뜻하지 않습니다.

전체 505개 공식 항목은 **업체명과 공식 링크**를 제공하며, 전시품·최신 동향·테마 분류는 심층 정리한 17개 업체에만 적용됩니다. 개별 회사가 공식 페이지에 제품을 공개하지 않은 경우에는 전시품 미공개라고 명시했습니다. 각 카드의 최신 동향과 방문 질문은 출처를 바탕으로 정리한 리서치 메모이며 전시회 출품 사실과 구분합니다.

첨부 보고서 원본은 저장소에 포함하지 않았고, 개인 연락처나 부스 담당자 이름도 공개하지 않았습니다.

## 실행

의존성이 없는 HTML/CSS/JavaScript 페이지입니다.

```sh
python3 -m http.server 8765
```

브라우저에서 `http://localhost:8765/`를 엽니다. 파일을 직접 더블클릭하면 브라우저의 로컬 파일 보안 정책 때문에 JSON을 읽지 못할 수 있습니다.

## 데이터 갱신

1. 공식 디렉터리에서 명단과 상세 페이지 ID를 확인해 `data/exhibitors-2026-raw.json`을 갱신합니다.
2. 새 출품 제품과 회사 발표를 확인해 `data/featured.json`의 문장, 부스, 출처를 갱신합니다. 업체명이 공식 명단에서 확인되지 않으면 `id`를 `null`로 둡니다.
3. `index.html`과 이 README의 스냅샷 날짜 및 수치를 함께 바꿉니다.

본문 출처는 각 업체 상세 카드에 연결되어 있습니다. 행사 일정·장소는 [CAMX 공식 FAQ](https://www.thecamx.org/faqs/)를 따릅니다.
